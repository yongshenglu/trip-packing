# 旅行装备清单

出游前的装箱清单工具：两个物品池（必带 / 非必带）、每次出游建清单、可存模板反复复用、勾选清点。

**打开即用**：https://yongshenglu.github.io/trip-packing/

## 功能

- **必带池 / 非必带池**：随时增删改，带分类标签（证件·电子·衣物·洗漱·药品·其他）
- **清单**：从两个池里勾选物品加入，带数量、备注、大勾选框与进度条
- **模板**：任何清单可「存为模板」，下次一键生成新清单（模板不被改动）
- **清单存快照**：池里删除物品不影响已建的历史清单
- **手机优先**：可添加到主屏（PWA），离线也能用

## 数据与隐私

- 网页代码公开，**代码里没有任何个人数据**。
- 数据在本机用口令加密（PBKDF2-SHA256 30 万次 → AES-GCM-256），密文才上传到你自己账号下的 **secret Gist**（一个叫 `packing.enc` 的文件）。Gist 不会被搜索、只有你的账号能读取。
- 口令只存在本机浏览器里，不上传；**口令丢失则云端密文无法恢复**（可用导出的加密文件 + 同一口令在新设备恢复）。
- GitHub 仓库只是「托管页面」，不存任何数据。

### 多端同步怎么开

1. 打开站点 → 设置 → 填「同步口令」（自己定一个长口令，一定要记住）
2. GitHub → Settings → Developer settings → **Personal access tokens → Fine-grained tokens**，只勾 **Gists: Read and write**，生成后填到「GitHub Token」
3. 点「立即上传」：会自动创建 secret Gist 并把 Gist ID 记在本机
4. 另一台设备打开同一网址，填同样的口令 + Token + Gist ID（或直接点「从云端下载」后粘贴 ID），即自动同步

改动后默认 2.5 秒自动上传；打开应用时若云端更新会自动拉取。

## 本地开发

纯静态，无构建：

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

注意：加密 API（`crypto.subtle`）只在 `https` 或 `localhost`/`127.0.0.1` 下可用，直接双击 `file://` 打开时同步功能会报错。
